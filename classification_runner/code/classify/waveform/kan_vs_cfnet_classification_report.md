# KAN vs CFNet 分类任务对比报告 (Waveform 数据集)

生成时间: 2026-02-10
数据集: UCI Waveform (5000)
- 样本数: 5000
- 特征数: 40
- 类别数: 3

## 实验配置

| 配置项 | 值 |
|--------|-----|
| 训练/验证/测试划分 | 70% / 15% / 15% |
| 训练轮数 | 200 (早停 patience=20) |
| 批次大小 | 128 |
| 学习率 | 0.005 |
| 正则化 | 1e-4 |
| 重复实验次数 | 10 次 (随机种子 42-51) |

## 模型架构对比

| 模型 | 参数量 | 架构特点 |
|------|--------|----------|
| **KAN** | **2,251** | 2层, hidden_dim=4, grid_size=10, spline_order=3 |
| CFNet_Standard | 679 | depth=5, poly_degree=3 |
| HybridRationalNet | ~500 | unit_degree=10, num_units=10 |

**注意**: KAN 的样条基函数机制导致其最小参数量较大（2,251 vs 679），这是 B-样条表示固有的特性。

## 核心结果对比

| 模型 | 平均准确率 | 标准差 | 最高准确率 | 最低准确率 |
|------|-----------|--------|-----------|-----------|
| **KAN** | **84.76%** | **1.58%** | **86.53%** | **82.40%** |
| HybridRationalNet | 84.25% | 1.16% | 86.53% | 82.40% |
| CFNet_Standard | 84.19% | 1.50% | 86.00% | 81.20% |

## 详细分析

### 1. 准确率对比

```
KAN (84.76%) > Hybrid (84.25%) > Standard (84.19%)
```

**观察**:
- **KAN 略微领先**，但优势很小（+0.5% vs Standard, +0.3% vs Hybrid）
- 所有模型的表现相当接近，差异在统计误差范围内
- KAN 的最高准确率（86.53%）与 Hybrid 持平

### 2. 稳定性对比

| 模型 | 标准差 | 稳定性评估 |
|------|--------|-----------|
| Hybrid | 1.16% | **最稳定** |
| Standard | 1.50% | 中等 |
| KAN | 1.58% | 略低 |

**观察**:
- Hybrid 的稳定性最好（标准差最小）
- KAN 虽然平均准确率最高，但波动略大

### 3. 10次实验详细结果

| Run | KAN | Hybrid | Standard |
|-----|-----|--------|----------|
| 1 | 86.53% | 85.73% | 85.73% |
| 2 | 85.87% | 83.47% | 86.00% |
| 3 | 83.60% | 82.40% | 82.00% |
| 4 | 84.93% | 84.27% | 83.33% |
| 5 | 85.73% | 84.40% | 84.67% |
| 6 | 82.67% | 84.00% | 85.07% |
| 7 | 83.07% | 83.33% | 85.33% |
| 8 | 82.40% | 83.47% | 84.40% |
| 9 | 86.40% | 86.53% | 84.13% |
| 10 | 86.40% | 84.93% | 81.20% |

**观察**:
- KAN 在 Run 1 和 Run 9-10 表现突出
- 各模型在不同随机种子下表现有波动
- 没有绝对的胜者，结果高度依赖初始化

## 关键发现

### 1. 表达能力
- KAN 的 B-样条基函数提供了良好的非线性表达能力
- 在 Waveform 这种非线性分类任务上，KAN 能达到与 CFNet 相当的效果

### 2. 参数效率
- **CFNet 明显更优**: 679 参数达到 84.19% 准确率
- **KAN 参数量大**: 2,251 参数（3.3倍）达到 84.76% 准确率
- 参数效率比: CFNet 约为 KAN 的 **3.3倍**

### 3. 训练特性
- KAN 训练稳定，收敛速度与 CFNet 相当
- 早停机制在所有模型上都有效

### 4. 对比回归任务
在噪声特征干扰回归任务中:
- KAN MSE: 0.0091
- CFNet MSE: 0.0087

在分类任务中:
- KAN Acc: 84.76%
- CFNet Acc: 84.19%

**结论**: KAN 在两种任务上都与 CFNet 相当，但没有明显优势。

## 综合评估

| 维度 | 胜出方 | 说明 |
|------|--------|------|
| **分类准确率** | KAN (微弱) | 84.76% vs 84.19% |
| **训练稳定性** | Hybrid | 标准差 1.16% |
| **参数效率** | CFNet_Standard | 679 参数 vs 2251 参数 |
| **综合性价比** | CFNet_Standard | 少量参数达到相似效果 |

## 结论

在 Waveform 分类任务上:

1. **KAN 表现良好**，准确率达到 84.76%，略优于 CFNet
2. **但参数量代价高**，需要 3.3 倍参数才能达到相当效果
3. **CFNet 系列（特别是 Hybrid）在参数效率和稳定性上更有优势**
4. **实际应用建议**: 如果参数量受限，选择 CFNet；如果追求极限准确率，可考虑 KAN
