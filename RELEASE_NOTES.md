# CFNN v1.0.0 — CAIC submission

Tag: `v1.0.0-caic`

This release freezes the code and reproducibility artifacts for the manuscript **“Continued fraction neural networks for sharp scientific response modelling”**, submitted to *Communications AI & Computing*.

## Included

- CFNN and CFNN-Hybrid implementations
- frozen experiment configurations and result schemas
- public-data source manifests and download tooling
- selected result manifests and figure-source arrays
- manuscript figure-generation scripts
- Apache-2.0 licence and release documentation
