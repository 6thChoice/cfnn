|------|-----------|---------------|---------------|------|

| Standard CFNet | 0.019 | 0.1056 | 0.0007 | 强 |

| MLP | 0.474 | 0.1365 | 0.0526 | 弱 |

**关键结论**:
- CFNet 的分式结构提供了强大的隐式正则化效果
- Hybrid CFNet 的噪声抑制率仅为 0.010，远低于 MLP 的 0.474
- CFNet 能有效抑制欺骗特征的虚假关联
